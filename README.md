## Hi there 👋 I'm Lâm

I'm **Nguyễn Đức Tùng Lâm**, a developer from Hanoi, Vietnam. I enjoy building open-source software across browsers, operating-system integration, web infrastructure, and cross-platform apps.

I'm currently focused on the **Fireball** browser family, Linux/Windows interoperability, and lightweight tools for desktop, mobile, and embedded systems.

### 🔥 Fireball browser projects

- [Fireball Blink](https://github.com/LamPPKK/fireball-blink) — Chromium/Blink builds and patch sets for Windows, macOS, Linux, and Android.
- [Fireball WebKit](https://github.com/LamPPKK/fireball-webkit) — a native SwiftUI and WKWebView browser for iOS, iPadOS, and macOS.
- [Fireball Docker](https://github.com/LamPPKK/fireball-docker) — a headless WPE WebKit container for VPS, cloud, and homelab remote browsing.

### 🖥️ System integration and compatibility

- [ATL-WSL](https://github.com/LamPPKK/ATL-WSL) — Android Translation Layer for WSL.
- [Darling-WSL](https://github.com/LamPPKK/Darling-WSL) — Darling integration for WSL.
- [Waydroid-WSL](https://github.com/LamPPKK/Waydroid-WSL) and [Waydroid-WSLg](https://github.com/LamPPKK/Waydroid-WSLg) — Waydroid experiments on Windows Subsystem for Linux.
- [iSteamOS](https://github.com/LamPPKK/iSteamOS) — an all-in-one SteamOS post-install toolkit.

### 🚀 Other projects

- [XanhTab](https://github.com/LamPPKK/XanhTab) — a Raspberry Pi kiosk stack using WPE WebKit, Rust, and Axum.
- [Kodepas](https://github.com/LamPPKK/kodepas) — a free and open-source software development kit for Pascal.
- [SmartMovie](https://github.com/LamPPKK/SmartMovie) — a native Swift movie-ranking app.
- [Android Smart Movie](https://github.com/LamPPKK/Android.Smart.Movie) — the Android companion built with Kotlin.
- [Zing Chart](https://github.com/LamPPKK/Zing-Chart) — a Dart app for exploring the Zing MP3 chart.
